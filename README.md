## File Uploader

a simple app for transfer files easily from your pc in web browser, not by cables or other app.

you can run it by python with flask, and pillow to generate thumbnail.

before run

    pip install flask pillow

run it like

    python fileup.py --port 8000 --root / --auth reg or noreg

![alt image](uploads/Screenshot.jpg)

## Features

- Of cource, upload and download files

- list view and grid view with bootstrap

- basic file operate include new folder, new file, edit text file, rename, move, copy, delete...or unknown problems

- zip and unzip files

- browse pictures with glightbox, you can make it clearly by use only picture mode

- very simple user authentication
